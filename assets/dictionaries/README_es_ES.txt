es_ES Hunspell Dictionary
=========================

Spanish (Spain) Hunspell dictionary for MiniPad, from the LibreOffice /
Apache OpenOffice Spanish dictionary project coordinated by RLA-ES.

Upstream:
  https://github.com/LibreOffice/dictionaries/tree/master/es

Files:
  es_ES.aff
  es_ES.dic
